# IT-Support-Ticketing-Lab

This repository contains various IT troubleshooting scenarios involving a ticketing system, demonstrating problem solving skills and  proficiency with a ticketing database.

For these labs I utilized Jira Service Management to replicate different end users issues
that I may encounter while working in an IT support environment. I worked through each ticket as 
the technician, while maintaining communication with the end-user who submitted the ticket, troubleshot the issue,
and documented the result.

Some of the tickets also involve my Windows Server 2022 Active Directory lab  and Windows 11 Client workstation, when an issue requires changes
to users domain account.

## Lab Setup

- Jira Service Management
- Windows Server 2022
- Windows 11 Client Workstation 
- Active Directory
- Oracle VirtulBox
- Group Policy Object
